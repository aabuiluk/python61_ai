NumPy-масиви та їх відмінність від списків Python

теорія

list у Python зручний як універсальний контейнер, але для числових обчислень він не оптимальний. NumPy ndarray зберігає елементи одного типу, має форму (shape) і працює швидко на векторних операціях.

Питанняlistndarray
Типи елементівможуть бути різнізазвичай один dtype
Форманеявнаshape, ndim, size
Поелементна арифметикачасто через циклвбудовано: arr + 10, arr * 2
Призначеннязагальна структура данихчисла, матриці, EDA, ML
 
import numpy as np

numbers = [1, 2, 3, 4]
arr = np.array(numbers, dtype=np.int64)

print(type(numbers), numbers)
print(type(arr), arr)
print(arr.dtype, arr.shape, arr.ndim)
print(arr * 10)
Додатково

Легко очікувати, що [1, 2, 3] * 2 дасть [2, 4, 6], але для списку це повторення, а не математика. У ndarray поелементне множення працює саме математично.

list

Різні типи, гнучко, повільні цикли для математики.

ndarray

Один dtype, contiguous buffer, ufuncs / broadcasting.

Векторизація, shape та базові операції над масивами

теорія

Векторизація означає: замість ручного циклу беремо весь масив одразу. Для аналізу даних це дає коротший, читабельніший і зазвичай швидший код.

import numpy as np

celsius = np.array([18.0, 21.5, 19.0, 24.5])
fahrenheit = celsius * 9 / 5 + 32
mask = celsius >= 20

print("F:", np.round(fahrenheit, 1))
print("теплі дні:", celsius[mask])
print("mean:", celsius.mean())

Broadcasting і форми масивів

теорія

Broadcasting — правила NumPy, як суміщати масиви різних форм без явного циклу.

  • Розміри порівнюються справа наліво; розмір 1 «розтягується».
  • Не очікуйте matrix multiply там, де працює element-wise *.
import numpy as np
a = np.array([[1, 2, 3], [4, 5, 6]])  # (2, 3)
b = np.array([10, 20, 30])             # (3,) → (1, 3) → (2, 3)
print(a + b)
print((a * b).sum(axis=1))
Навіщо. Векторизація + broadcasting = швидший і коротший код аналізу даних перед pandas/ML.

Місток від ndarray до Series і DataFrame

теорія

Series — це один підписаний стовпець, а DataFrame — двовимірна таблиця. Дуже часто ми починаємо з np.array, а потім загортаємо результат у pandas, коли хочемо підписи, індекси та табличні методи.

import numpy as np
import pandas as pd

scores = np.array([92, 88, 95], dtype=np.int64)
series = pd.Series(scores, index=["Olena", "Taras", "Ira"], name="score")
df = pd.DataFrame({"name": series.index, "score": series.values, "passed": series.values >= 90})

print(series)
print(df)

Додатково: axis, reshape і булева маска без сюрпризів

додатковий матеріал

Головне на цій парі: list ≠ ndarray, векторизація, axis, reshape/transpose, булева індексація. Масив 3×5 варто зібрати до задачі 3.

import numpy as np
a = np.arange(15).reshape(3, 5)
print(a.shape, a.T.shape)
print("sum axis=0 (по рядках → 5 чисел):", a.sum(axis=0))
print("sum axis=1 (по стовпцях → 3 числа):", a.sum(axis=1))
assert a.size == 3 * 5

argmin на 2D дає плоский індекс — розгортайте через np.unravel_index.

Зверніть увагу
  • плутають axis=0 і axis=1;
  • reshape без перевірки size;
  • Python min() замість np.min;
  • друкують argmin як одне число, без координат рядка/стовпця.
Джерела
  • Harris et al., Nature 2020 — чому ndarray є основою наукового стека.

З numpy.org (absolute basics): ndim — скільки осей, shape — довжина кожної, size — добуток вимірів. reshape не змінює дані, лише форму; якщо size не збігається — буде помилка, і це добре.

import numpy as np
a = np.arange(15).reshape(3, 5)
print(a.ndim, a.shape, a.size)
flat = np.argmin(a)
print("плоский індекс", flat, "→", np.unravel_index(flat, a.shape))
pos = a[(a > 0) & (a % 2 == 0)]  # булева маска, задача 5

concatenate склеює вздовж наявної осі; stack додає нову. Для задачі 6 Практичного 2.1 це різні відповіді (вектор 10 vs матриця 2×5).

3. Views vs copies

  • Зріз часто повертає view — зміна view змінює base.

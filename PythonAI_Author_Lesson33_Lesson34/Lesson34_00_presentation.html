За Жероном · DBSCAN: кластери як густі області

книжка

DBSCAN визначає кластери як суцільні області високої щільності.

Працює він так.

  • Для кожного прикладу алгоритм рахує, скільки прикладів лежить на малій відстані ε (епсилон) від нього. Ця область називається ε-околом прикладу.
  • Якщо в ε-околі прикладу є щонайменше min_samples прикладів (разом із ним самим), він вважається ядровим. Тобто ядрові приклади — ті, що лежать у густих областях.
  • Усі приклади в околі ядрового належать до того самого кластера. В околі можуть бути інші ядрові приклади, тому довгий ланцюжок сусідніх ядрових прикладів утворює один кластер.
  • Приклад, який не є ядровим і не має ядрових у своєму околі, вважається аномалією.

Алгоритм добре працює, якщо всі кластери чітко розділені областями низької щільності. У книжці його перевіряють на наборі moons — двох півмісяцях.

DBSCAN з двома радіусами околу

Великі точки — ядрові, малі — граничні, рожеві хрестики — аномалії. У книжці цьому відповідає рис. 8-13. Графік побудовано кодом нижче, а не взято з книжки.

Показати графік

Запустіть код — отримаєте той самий рисунок і числа під ним.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=1000, noise=0.05, random_state=42)

fig, axes = plt.subplots(1, 2, figsize=(9.6, 3.6), sharex=True, sharey=True)
for ax, eps in zip(axes, (0.05, 0.2)):
    dbscan = DBSCAN(eps=eps, min_samples=5).fit(X)
    labels = dbscan.labels_
    core = np.zeros(len(X), dtype=bool); core[dbscan.core_sample_indices_] = True
    noise = labels == -1
    ax.scatter(X[core, 0], X[core, 1], s=14, c=labels[core], cmap="tab10")                 # ядрові точки
    ax.scatter(X[~core & ~noise, 0], X[~core & ~noise, 1], s=5, c=labels[~core & ~noise], cmap="tab10")
    ax.scatter(X[noise, 0], X[noise, 1], marker="x", s=30, color="#ff8fab")                # аномалії
    n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
    ax.set_title(f"eps = {eps}, min_samples = 5")
    ax.set_xlabel("x1")
    print(f"eps = {eps}: кластерів {n_clusters}, ядрових точок {core.sum()}, аномалій {noise.sum()}")
axes[0].set_ylabel("x2")
fig.tight_layout()
plt.show()
# -> eps = 0.05: кластерів 7, ядрових точок 808, аномалій 77
# -> eps = 0.2: кластерів 2, ядрових точок 1000, аномалій 0

Мітки. Після навчання мітки лежать у labels_. Частина прикладів має мітку −1: алгоритм вважає їх аномаліями. Індекси ядрових прикладів — у core_sample_indices_, самі ядрові приклади — у components_.

Що вийшло. З eps=0.05 алгоритм знайшов сім кластерів і чимало аномалій — результат розчаровує. Якщо розширити окіл до eps=0.2, виходить кластеризація, яка виглядає ідеально: два півмісяці, жодної аномалії.

За Жероном · нові приклади: чому немає predict()

книжка

У класу DBSCAN немає методу predict(), хоча є fit_predict(). Він не вміє сказати, до якого кластера належить новий приклад.

Так вирішили свідомо: для різних задач кращими можуть бути різні алгоритми класифікації, тож вибір лишили користувачеві. Реалізувати це нескладно. У книжці навчають KNeighborsClassifier на 50 сусідах — на ядрових прикладах і їхніх мітках.

Межа рішень між двома кластерами

Фон — до якого кластера класифікатор віднесе точку; плюси — чотири нові приклади. У книжці цьому відповідає рис. 8-14. Графік побудовано кодом нижче, а не взято з книжки.

Показати графік

Запустіть код — отримаєте той самий рисунок і числа під ним.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=1000, noise=0.05, random_state=42)
from sklearn.neighbors import KNeighborsClassifier

dbscan = DBSCAN(eps=0.2, min_samples=5).fit(X)
knn = KNeighborsClassifier(n_neighbors=50)
knn.fit(dbscan.components_, dbscan.labels_[dbscan.core_sample_indices_])   # вчимо на ядрових точках
X_new = np.array([[-0.5, 0], [0, 0.5], [1, -0.1], [2, 1]])

xx, yy = np.meshgrid(np.linspace(-1.6, 2.6, 400), np.linspace(-1.0, 1.6, 300))
zones = knn.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
fig, ax = plt.subplots(figsize=(6.6, 3.8))
ax.contourf(xx, yy, zones, alpha=0.25, cmap="tab10")
ax.scatter(X[:, 0], X[:, 1], s=6, c=dbscan.labels_, cmap="tab10")
ax.scatter(X_new[:, 0], X_new[:, 1], marker="P", s=110, color="#ff8fab", edgecolors="black", zorder=3)
ax.set_title("Межа між двома кластерами і 4 нові точки")
ax.set_xlabel("x1"); ax.set_ylabel("x2")
fig.tight_layout()
plt.show()

print("кластери нових точок:", knn.predict(X_new))
print("ймовірності:")
print(knn.predict_proba(X_new).round(2))
dist, idx = knn.kneighbors(X_new, n_neighbors=1)           # відстань до найближчої ядрової точки
pred = dbscan.labels_[dbscan.core_sample_indices_][idx]
pred[dist > 0.2] = -1                                      # далі ніж 0.2 — вважаємо аномалією
print("з обмеженням відстані 0.2:", pred.ravel())
# -> кластери нових точок: [1 0 1 0]
# -> ймовірності:
# -> [[0.18 0.82]
# ->  [1.   0.  ]
# ->  [0.12 0.88]
# ->  [1.   0.  ]]
# -> з обмеженням відстані 0.2: [-1  0  1 -1]

Тепер для нових прикладів можна передбачити найімовірніший кластер і навіть оцінити ймовірність кожного — у виводі це 0.82 і 0.88 для двох точок і 1.0 для двох інших.

Класифікатор навчено лише на ядрових прикладах, але можна було б узяти всі приклади або всі, крім аномалій: вибір залежить від кінцевої задачі.

Далекі точки. У навчальному наборі класифікатора аномалій немає, тому він завжди вибирає якийсь кластер, навіть коли той далеко. Легко ввести граничну відстань — тоді два приклади, далекі від обох кластерів, стануть аномаліями. Для цього метод kneighbors() повертає відстані до найближчих сусідів; усе, що далі ніж 0.2, отримує мітку −1. В останньому рядку виводу саме це: [-1, 0, 1, -1].

k-means проти DBSCAN на півмісяцях

k-means проводить пряму межу між двома центроїдами і ріже обидва півмісяці. DBSCAN іде вздовж густих областей. Графік побудовано кодом нижче, а не взято з книжки.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=1000, noise=0.05, random_state=42)
from sklearn.cluster import KMeans
from sklearn.metrics import adjusted_rand_score

kmeans = KMeans(n_clusters=2, n_init=10, random_state=42).fit(X)
dbscan = DBSCAN(eps=0.2, min_samples=5).fit(X)

fig, axes = plt.subplots(1, 2, figsize=(9.6, 3.6), sharex=True, sharey=True)
for ax, labels, title in zip(axes, (kmeans.labels_, dbscan.labels_), ("k-means, k = 2", "DBSCAN, eps = 0.2")):
    ax.scatter(X[:, 0], X[:, 1], s=6, c=labels, cmap="tab10")
    ax.set_title(title); ax.set_xlabel("x1")
c = kmeans.cluster_centers_
axes[0].scatter(c[:, 0], c[:, 1], marker="X", s=90, color="#ff8fab", edgecolors="black")
axes[0].set_ylabel("x2")
fig.tight_layout()
plt.show()

print("k-means: збіг зі справжніми півмісяцями (ARI):", round(adjusted_rand_score(y, kmeans.labels_), 3))
print("DBSCAN : збіг зі справжніми півмісяцями (ARI):", round(adjusted_rand_score(y, dbscan.labels_), 3))

DBSCAN для груп довільної форми

сьогодні

Тут немає K. Є радіус eps і мінімум сусідів min_samples. Точка з достатньою кількістю сусідів у радіусі — ядро групи. Точка без сусідів — шум, не «ще один кластер».

K-means тягне групи до круглих куль навколо центру. Витягнута ковбаса або кільце ріжеться погано. DBSCAN зшиває точки, які дістають одна одну в радіусі eps.

eps і min_samples задаємо ми. Завеликий eps склеює все в одну групу. Замалий лишає майже всі точки шумом.

Шум — це мітка, не група з центром. Її не треба називати кластером номер 0, якщо 0 вже зайнятий під справжню групу. У багатьох реалізаціях шум якраз позначений −1.

Що задаємо ми

eps і min_samples. Кількості груп заздалегідь немає.

Що виходить

Мітка групи або шум для кожної точки.

Чим не K-means

Немає центрів, які треба заздалегідь порахувати. Форма групи може бути кривою.

from __future__ import annotations

try:
    points = [(0.0, 0.0), (0.2, 0.1), (5.0, 0.0), (5.1, 0.1)]

    def k_distance(sample, k=2):
        dists = []
        for x, y in sample:
            others = sorted(((x - a) ** 2 + (y - b) ** 2) ** 0.5 for a, b in sample)
            dists.append(others[k])
        return sorted(dists)

    def noise_frac(sample, eps):
        labels = []
        for x, y in sample:
            n = sum(((x - a) ** 2 + (y - b) ** 2) ** 0.5 <= eps for a, b in sample)
            labels.append(-1 if n < 2 else 0)
        return labels.count(-1) / len(labels)

    raw = [(x * 80, y) for x, y in points]
    print('eps_hint', k_distance(points)[-2], 'raw_noise', noise_frac(raw, 0.8), 'scaled_noise', noise_frac(points, 0.8))
    assert noise_frac(raw, 0.8) >= noise_frac(points, 0.8)
except ModuleNotFoundError as exc:

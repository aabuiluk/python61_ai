Розподіл випадкової величини: не тільки “центр”, а й форма

теорія

Однакове середнє ще не означає однакові дані. Розподіл показує, як часто трапляються значення: де основна маса, чи є хвости, чи є перекіс, чи є дискретні “сходинки”.

Графік · три форми розподілу

Що помічати

Симетрія

Чи схожі лівий і правий боки.

Пік

Один центр чи кілька локальних піків.

Хвости

Чи часто трапляються далекі значення.

Практична рамка

На парі не вчимося доводити формули. Наша мета — навчитись бачити розподіл у таблиці й робити з цього корисні для EDA висновки.

Емпірична функція розподілу Fn(x) = (кількість Xi ≤ x) / n. Дві вибірки з mean = 50 можуть мати різну Fn: рівномірна на {0, 50, 100} і купка {49, 50, 51}. У точці 40 перша дає F=1/3, друга F=0 — форма розійшлася, центр ні.

Для хвилин відповіді Fn(60) — це частка тікетів всередині SLA, не «середня хвилина». Mean може бути 45 хв при F(60)=0.70, якщо хвіст 200 хв тягне центр. Розподіл відповідає на поріг; одне середнє — ні.

Коротко

Коли питають «скільки вклались у 60 хв?», рахуйте F_n(60), не порівнюйте mean з 60 «на око».

Додатково: гістограма — емпірична, не PDF; bins змінюють «форму»

додатковий матеріал

Однакове mean ще не означає однаковий розподіл: два ряди можуть мати спільний центр і різну масу в хвостах. Гістограма оцінює форму цієї вибірки. Кількість бінів — гіперпараметр: занадто мало — все «нормальне», занадто багато — пила з порожніх стовпчиків.

import numpy as np
rng = np.random.default_rng(0)
x = rng.normal(0, 1, 400)
c5, _ = np.histogram(x, bins=5)
c40, _ = np.histogram(x, bins=40)
print(c5.sum(), c40.sum())  # обидва 400 — маса та сама, форма різна
  • density=True нормує площу до 1 (схоже на PDF), але це все одно оцінка з бінів, не формула щільності.
  • Дискретний рейтинг 1..5 краще малювати bar частот, не hist з довільними бінами.
  • Дивіться симетрію, кількість піків, хвости — не «назву розподілу» з підручника.
Часта пастка

Дві гістограми «різні», бо bins=8 і bins=30. Спочатку зафіксуйте bins або bins="auto", потім порівнюйте форми.

Гістограма оцінює щільність кусками сталої висоти; PDF — неперервна модель. Зміна bins змінює висоти так, що «дві моди» можуть зʼявитись і зникнути. Це артефакт бінування, не обовʼязково властивість генератора.

Зверніть увагу: density=True нормує площу до 1, не висоти стовпчиків. Порівнювати «висоту біна» між двома hist з різною шириною біна без density — безсенсово.

Для викладача: np.histogram vs KernelDensity

Для викладача

Інваріант: сума counts = n (для скінченних країв, якщо немає out-of-range). density=True нормує sum(count * bin_width) = 1, не sum(count)=1. Плутанина цих двох дає «ймовірності» по 40% на бін.

sklearn KernelDensity / SciPy gaussian_kde — згладжена оцінка, теж не справжня PDF процесу. На цій парі достатньо histogram; KDE не є «точнішою правдою», лише інший bias-variance.

Не підганяйте bins, щоб вибірка «стала нормальною». Для моделі важливіше рішення log/robust, ніж підпис «≈ N(μ,σ²)».

np.histogram повертає counts і edges; plt.hist малює bar по цих edges. KernelDensity (sklearn) — інша оцінка: bandwidth замість bins. Немає єдиної «правильної» кількості бінів; Freedman–Diaconis / Sturges — евристики.

Для дискретних лічильників hist із занадто вузькими bins малює гребінку. Тоді доречніший bar по value_counts, не hist неперервної осі.

У Пуассона mean = variance = λ. Якщо тікетів за годину в середньому 4, модель обіцяє і розкид 4 (std = 2). P(X=0) = e−λ ≈ 0.018: порожня година рідкісна, але не неможлива. Якщо у даних variance ≫ mean, це уже overdispersion — не той шаблон.

Коваріація: чи змінні рухаються в один бік

теорія

Коваріація показує, чи відхилення двох змінних від своїх середніх узгоджені за знаком. Якщо одна зазвичай зростає разом з іншою — коваріація додатна; якщо навпаки — відʼємна.

import numpy as np

study_hours = np.array([2, 3, 4, 5, 6, 7], dtype=float)
scores = np.array([58, 63, 67, 74, 79, 85], dtype=float)
cov = np.cov(study_hours, scores, ddof=1)[0, 1]
print("covariance:", round(cov, 2))

Scatter · спільна зміна

Обережно

Саме число коваріації важко порівнювати між задачами, бо воно залежить від масштабу вимірювання: години × бали, сантиметри × кілограми, гривні × штуки.

Формула: cov = Σ(x − x̄)(y − ȳ) / (n − 1). Нехай години [2, 4, 6], бали [60, 70, 80]. x̄=4, ȳ=70. Добутки відхилень: (−2)·(−10)+0+2·10 = 40. cov = 40/2 = 20 (години·бали). Знак «+»: більші години з більшими балами.

На черзі той самий механізм: x = хвилини до відповіді, y = 1 якщо P1. Додатна cov означає, що P1 частіше живе з довшими хвилинами. Величина 20 vs 0.02 нічого не каже без одиниць: порівнювати cov між парами колонок можна лише після однакової шкали.

xs, ys = [2, 4, 6], [60, 70, 80]
mx, my = 4, 70
print(sum((x-mx)*(y-my) for x, y in zip(xs, ys)) / 2)
Коротко

Знак cov читається одразу. Модуль — лише разом з одиницями x і y.

Для викладача: np.cov rowvar і EmpiricalCovariance

Для викладача

Інваріант: cov(aX, Y) = a·cov(X,Y), cov(X,X)=var(X). Масштаб фічі в sklearn лінійно змінює cov і не змінює Pearson r. Саме тому кореляція, не cov, іде в feature_selection як порівнянна метрика.

numpy.cov default rowvar=True: shape (2, n) очікує змінні в рядках. Передати два вектори (n,) працює, але матриця спостережень (n, 2) потребує rowvar=False. Тихий транспонований cov — баг на роки.

sklearn EmpiricalCovariance / Ledoit-Wolf — оцінка Σ для GaussianNB-подібних моделей і outlier detection, не заміна scatter plot.

np.cov(m, rowvar=False, ddof=1) узгоджується з pandas.DataFrame.cov. sklearn EmpiricalCovariance оцінює іншу регуляризовану/MLE-версію — не звіряйте 1-1 без читання estimator.

Коваріаційна матриця має бути SPSD; після feature engineering з лінійно залежними колонками вона вироджена, і np.linalg.inv падає. Це сигнал колінеарності, не баг cov.

Кореляція: нормований звʼязок у діапазоні -1..1

теорія

Кореляція — це коваріація, нормована на стандартні відхилення двох змінних. Тому значення легше читати: 1 — сильний прямий лінійний звʼязок, -1 — сильний обернений, 0 — лінійного звʼязку майже немає.

import pandas as pd

df = pd.DataFrame(
    {
        "hours": [2, 3, 4, 5, 6, 7],
        "score": [58, 63, 67, 74, 79, 85],
    }
)
print(df.corr(numeric_only=True))
print("pearson r =", round(df["hours"].corr(df["score"]), 3))

Графік · сила кореляції

Памʼятка

r ≈ 0.8

Сильний додатний лінійний звʼязок.

r ≈ -0.7

Сильний відʼємний лінійний звʼязок.

r ≈ 0

Або звʼязку мало, або він нелінійний.

Головне попередження

Correlation does not imply causation. Висока кореляція ще не доводить, що одна змінна є причиною іншої.

Pearson: r = cov(x, y) / (sx sy). Якщо sx=0 (усі хвилини однакові), знаменник нуль — r не визначений, не «дорівнює 0». На трійці годин/балів вище sx=2, sy=10, cov=20 → r = 20/20 = 1: ідеальна пряма.

Квадрат r² — частка дисперсії y, яку лінійно «пояснює» x. При r=0.6 маємо r²=0.36: 36% розкиду балів узгоджені з годинами лінійно, 64% — ні. Це не доказ причини і не якість моделі з нелінійним звʼязком.

Часта пастка

r=0 не означає «звʼязку немає». Парабола y=x² на симетричному x дає r≈0 при жорсткій залежності. Дивіться scatter.

теорія

Кореляція ≠ причинність. Сильний звʼязок може бути через confounder, зворотну причинність або випадковість.

y = 2 * x + rng.normal(0, 0.5, 200)
print("corr", np.corrcoef(x, y)[0, 1].round(3))

# викид

2. Uniform / normal / Poisson — інтуїція

  • Uniform — «все між a і b однаково ймовірно» (ідеалізація).
  • Normal — сума багатьох малих незалежних ефектів (CLT як орієнтир, не догма).
  • Poisson — лічильні події за інтервал при рідкісних незалежних подіях.

3. Causation checklist

  1. Чи є механізм / domain knowledge?
  2. Чи контролюємо спільні причини?
  3. Чи є часовий порядок?

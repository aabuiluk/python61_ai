# Пари 39–42 · Український практикум · 180 хв

Основа — наданий HTML із плаваючим меню. 39–40: 40 хв повторення; 41: 70 хв RAG; 42: 70 хв агента. Відкрийте PythonAI_Author_Lesson41_Lesson42.html: зелена картка після прикладу показує, яке завдання виконати зараз.

## Налаштування

Скопіюйте .env.example у .env і вставте власний OPENAI_API_KEY. Встановіть requirements.txt. Запити оплачуються окремо через OpenAI API.

## Завдання 00. Перевірка ключа й першого запиту

Коли: після прикладу теми topic-1.

Після налаштування .env виконайте перевірку доступу до API. Змініть input на власне питання українською про роботу магазину у Львові.

Файли: tasks/task_00.py, requests/ua_task_00.json.

Критерій: Є відповідь справжньої моделі, model/status/usage; ключ не потрапив у результат.

## Завдання 01. Zero-shot та Few-shot для відгуків

Коли: після прикладу теми topic-4.

Після прикладу класифікатора запишіть п’ять відгуків про український магазин. Надішліть кожний двічі: без прикладів і з трьома власними прикладами. Реалізуйте перевірку дозволених міток.

Файли: tasks/task_01.py, requests/ua_task_01.json.

Критерій: Таблиця десяти живих відповідей, очікувані мітки й usage. Невідома мітка відхиляється.

## Завдання 02. Critic та Editor

Файли: tasks/task_02.py, requests/ua_task_02.json.

Критерій: Збережено початкову відповідь, зауваження і виправлення. Результат вручну звірено з джерелом.

Критерій: Є дві живі відповіді; для невідомого факту перевірено відмову без вигаданого імені.

Файли: tasks/task_04.py, requests/ua_task_04.json.

Критерій: Один живий API-запит і три локальні перевірки. Сервіс OpenAI не названо Google Vertex.

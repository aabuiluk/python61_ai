- `python -m PythonAI_Author_Lesson41_Lesson42.examples.review_pipeline`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.grounded_answer`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.rag_live`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.chunks_demo`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.search_demo`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.rag_guard`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.retrieval_metrics`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.agent_live`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.app`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.tool_validation`
- `python -m PythonAI_Author_Lesson41_Lesson42.examples.api_minimal`

API-приклади роблять реальні оплачувані запити. Для локальної перевірки без мережі: chunks_demo.py, search_demo.py, retrieval_metrics.py. Повні розв’язки практичних задач — у викладацькій методичці.

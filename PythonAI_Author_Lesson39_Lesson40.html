import json
import csv
from pathlib import Path
CATALOG = [
    {"id": "b01", "title": "Python старт", "price": 320, "topic": "python"},
    {"id": "b02", "title": "Практика Python", "price": 450, "topic": "python"},
    {"id": "b03", "title": "Основи даних", "price": 390, "topic": "data"},
]
SOURCE = "[S1] Книга b01 коштує 320 грн. [S2] Повернення можливе протягом 14 днів."
def validate(raw):
    try:
        obj = json.loads(raw)
    except (json.JSONDecodeError, TypeError):
        return False
    if not isinstance(obj, dict) or set(obj) != {"book_id", "price"}:
        return False
    return any(obj["book_id"] == b["id"] and type(obj["price"]) is int
               and obj["price"] == b["price"] for b in CATALOG)
def chunks(text, size=12, overlap=3):
    if type(size) is not int or type(overlap) is not int or not 0 <= overlap < size:
        raise ValueError("Потрібно: size > overlap >= 0")
    words = text.split()
    result = []
    start = 0
    while start < len(words):
        result.append(" ".join(words[start:start+size]))
        if start+size >= len(words):
            break
        start += size-overlap
    return result

Блок 3. 39.1 · Декомпозиція замість магічної фрази

30–55 хв.

Факт. Складну задачу зручніше розбити на результати, які можна перевірити окремо.

Chain of Thought (CoT) історично означає промпти з проміжними міркуваннями. У сучасному практикумі вимагайте короткий план, перевірювані обчислення та підсумок; повна прихована траса мислення не потрібна. Пояснення моделі саме по собі не доводить правильності.

Приклад: покупець має 800 грн. Дві книги по 320 коштують 640, залишок 160. Якщо розділити задачу на пошук ціни → множення → порівняння з бюджетом, можна перевірити кожен результат. Арифметику виконує Python. LLM може оформити коротке пояснення вже перевірених значень. Це корисніше за безумовну віру у фразу «думай крок за кроком».

Блок 4. 39.2 · ReAct: запит, дія, спостереження

55–80 хв.

Факт. Назва інструмента в тексті ще не означає, що інструмент був виконаний.

ReAct поєднує планування дії та отримання спостереження. У нашій простій реалізації чат пропонує JSON-запит, Python перевіряє дозволену назву дії й аргументи, виконує пошук, а отриманий результат ми вручну повертаємо в чат. Це один справжній цикл із людиною як диспетчером. Кілька реплік моделі «Action/Observation» без виконання — лише імітація.

Дозволимо тільки lookup_book. Невідомий id дає None, а невідома дія — помилку. Жоден рядок із чату не виконуємо через eval або exec. Модель не має самостійного доступу до БД. Після результату пошуку фінальна відповідь має спиратися саме на повернений запис.

Живий промпт прикладу: «Доступна дія lookup_book(book_id). Потрібна ціна b01. Поверніть тільки {"action":"lookup_book","book_id":"b01"}. Не вигадуйте observation». Виконайте lookup у Python та наступною реплікою передайте фактичний результат.

Приклад · основний код

request = {"action":"lookup_book", "book_id":"b01"}  # ручний запит
if request["action"] != "lookup_book":
    raise ValueError("Недозволена дія")
observation = next((b for b in CATALOG if b["id"] == request["book_id"]), None)
print(json.dumps({"observation":observation}, ensure_ascii=False))

{"observation": {"id": "b01", "title": "Python старт", "price": 320, "topic": "python"}}

Блок 5. 39.3 · ToT: альтернативи, критерій, вибір

80–105 хв.

Факт. Кілька альтернатив корисні лише разом із явним правилом відбору.

Tree of Thoughts (ToT) досліджує кілька можливих продовжень із оцінюванням і пошуком. Ми реалізуємо навчальний фрагмент: кандидати → фільтр бюджету → вибір. Одноразове прохання «дай три варіанти» не є повною реалізацією алгоритму ToT із поверненням до попередніх станів.

Для магазину спершу відкиньте пропозиції понад бюджет. Серед решти максимізуйте тематичну відповідність, при рівності оберіть нижчу ціну. Такий порядок критеріїв важливий: висока релевантність не дозволяє порушити жорстке обмеження. Якщо жоден кандидат не проходить, правильний результат — None, а не вигадана знижка. Оцінки нижче задані вручну, не LLM.

Живий промпт прикладу: «Кандидати A: 320 грн, relevance 2; B: 450 грн, relevance 3. Бюджет 400. Відкиньте перевищення бюджету, оберіть найрелевантніший допустимий. Поверніть id і коротку перевірювану причину».

## 16. 40.4 · Зібрати, перевірити, зберегти

### Промпт: Gemini або ChatGPT

**Gemini:** AI Studio або Gemini → новий текстовий чат → вставте промпт нижче → Run/Send.

**ChatGPT — альтернатива:** chatgpt.com → звичайний Chat → New chat → вставте той самий повний промпт нижче → надішліть. Платна підписка й API не потрібні.

Якщо промпт має кілька фаз, надсилайте їх послідовно після перевірки кожного результату. За недоступності безкоштовного чату виконайте ручні fixtures; позначте mode=fixture.

```text
Ви консультант магазину. Дозволені записи:

Варіант v2 для окремого порівняння: додайте перед цим запитом приклад
```

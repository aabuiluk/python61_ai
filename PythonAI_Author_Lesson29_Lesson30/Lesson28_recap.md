# Пара 28 · що треба памʼятати перед парами 29–30

Пари 29–30 спираються на пару 28. Повна презентація — `Lesson28_00_presentation.html`, приклад — `Lesson28_05_words_to_sequences.py`.

## Головне з пари 28

| Поняття | Коротко | Де знадобиться |
|---|---|---|
| Embedding | слово → щільний вектор, наприклад зі 100 чисел, замість one-hot з тисяч нулів | перший шар кожної моделі пар 29–30: `nn.Embedding` |
| Косинусна схожість | `cos(a, b) = a·b / (|a|·|b|)`, від −1 до 1 | увага (attention) теж міряє схожість скалярним добутком |
| Word2Vec | вектори вчаться передбачати сусідів слова у вікні | ідея «значення = контекст» |
| GloVe | вектори підбираються під матрицю співпоявлень усього корпусу | готові вектори 6B для transfer learning на парі 30 |
| Найближчі сусіди | слова з найбільшим косинусом | чому модель з GloVe розуміє `cash back` і `cannot remember` |
| Середній вектор речення | середнє векторів слів | пошуковик-база для порівняння; не бачить порядку слів |

## Запуск

```bash
python Lesson28_05_words_to_sequences.py
python Lesson28_05_words_to_sequences.py "my parcel is lost"
```

GloVe у цьому пакеті — `assets/glove/glove_100d.bin`: той самий файл, що в пакеті пар 27–28, плюс слова служби підтримки. Читається без gensim: `supportflow.load_glove()`.

## Перевір себе

1. У словнику 25 000 слів. Скільки чисел в one-hot векторі одного слова, а скільки в embedding GloVe?
2. Чому `cos("refund before delivery", "delivery before refund") = 1` для середнього вектора?
3. Чому GloVe знає, що `cash` схоже на `money`, хоча слова `cash` немає в даних SupportFlow?
4. Пошуковик знайшов відповідь на 10 з 15 нових запитів. Яку відповідь він дасть на запит, тема якого в базі відсутня?

# Пари 35–36 · рекомендації книг

Студент: tasks містять умови, підказки й місце для вашого коду.

40 хв місток 33–34, 100 хв content-based, 100 хв collaborative filtering.
Почніть із маршруту PythonAI_Author_Lesson35_Lesson36.md / .ipynb / .html у батьківській папці.

## Структура

- examples/example_01.py … example_10.py: кожен приклад запускається окремо.
- tasks/task_01.py … task_10.py: ті самі 10 завдань, що в ноутбуці; поруч умови у .md.
- data/books.csv і ratings.csv: локальні навчальні дані.
- workshop.py: ті самі дані та допоміжні функції; без мережі.
- results/: CSV після виконання експорту.

## Запуск

Активуйте .venv спільного репозиторію. Або встановіть залежності тільки цієї папки: python -m pip install -r requirements.txt.
З кореня пакета: python examples/example_01.py; python tasks/task_01.py.
Можна також запускати з кореня репозиторію, вказавши шлях до файла.

Кожен .py розділений маркерами # %% на контекст, основний код та окрему візуалізацію.
В IDE виконуйте їх як комірки. При запуску всього файла закрийте вікно Matplotlib, щоб процес завершився.
Збереження картинки замість вікна: замініть plt.show() у графічному блоці на fig.savefig('figure.png',dpi=150).
Графічний блок не потрібно переписувати для розв’язання алгоритмічної частини.

Пакет використовує наявні numpy, pandas, matplotlib та scikit-learn. Нових сторонніх залежностей немає.
Для CSV використано UTF-8 із BOM. Реальні оцінки не підміняємо нулями; train/test поділено за спільним часом.

# Домашнє · пара 22. Ядро, карта і другий шар

Зробіть один скрипт. Суми вікна порахуйте самі, не підглядаючи в коментар.

## 1

Вікно 3×3: у кожному рядку зліва 0, посередині 0, справа 9. Ядро в кожному рядку `1, 0, -1`. Сума має бути −27.

## 2

Те саме ядро на вікні, де всі девʼять пікселів дорівнюють 4. Сума має бути 0.

## 3

Порахуйте ваги другого шару `Conv2d(16, 32, 3)`: одне ядро це 3×3×16 = 144, увесь шар 144×32 = 4608. Для кадру 32 без доповнення краю карта першого ядра 3×3 має сторону 30, не 32.

## 4

Одним реченням: цикл навчання на цифрах — наступна пара. Тут достатньо суми вікна і форми карти.

Рубрика (100): коректність сум, assert, читабельні імена, край «рівне поле дає 0», речення з пункту 4.

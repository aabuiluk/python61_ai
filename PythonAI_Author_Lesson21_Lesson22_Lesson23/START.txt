Середовище Windows:

  python -m venv .venv
  .venv\Scripts\activate
  python -m pip install -U pip
  python -m pip install -r requirements.txt

Середовище macOS / Linux:

  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -U pip
  python -m pip install -r requirements.txt

PCA: побачити 100D на площині

сьогодні

PCA знаходить два напрями з найбільшою варіацією і проєктує вектори. Відстань на графіку — підказка; similarity рахуйте cosine у вихідному просторі.

from sklearn.decomposition import PCA
import matplotlib.pyplot as plt
words = list(model.wv.index_to_key)[:20]
vectors = [model.wv[w] for w in words]
points = PCA(n_components=2).fit_transform(vectors)
plt.scatter(points[:, 0], points[:, 1])
for word, (x, y) in zip(words, points):
    plt.annotate(word, (x, y))
plt.savefig("results/word2vec_visualization.png")

Схематичний scatter після PCA

Практика

  1. A. Три слова, topn=5, що логічно / що шум через корпус.
  2. B. Дві моделі: window=1 і window=4, порівняти сусідів одного слова.
  3. C. До 20 слів, scatter, хоча б одна група зі спільним контекстом.

Найближчі слова у Word2Vec і GloVe

сьогодні

Для слова беруть його вектор і шукають інші слова з найменшою відстанню. Це перевірка таблиці, не окрема модель класифікації.

Косинус близько 1 — вектори дивляться в один бік. Близько 0 — майже перпендикулярні. Відʼємний — у протилежні.

Сусід «поганий» біля «хороший» не означає, що модель плутає оцінку. Вони часто стоять у схожих реченнях.

Готова таблиця GloVe не знає наших рідкісних слів. Невідоме слово не має вектора, доки ми не задамо запасний.

Що вже лежить у таблиці

Вектори. Пошук сусідів їх не навчає заново.

10. Word2Vec

Другий прогін закриває ту саму ідею іншим фрагментом. Запустіть комірку цілком.

from collections import Counter
window = ["the", "cat", "sat", "on", "the", "mat"]
ctr = Counter()
for i, w in enumerate(window):
    for j in range(max(0, i-1), min(len(window), i+2)):
        if i != j:
            ctr[(w, window[j])] += 1
print(ctr.most_common(2))
assert ctr[("the", "cat")] >= 1

Рядок за рядком.

  1. from collections import Counter — Імпорт. Імʼя модуля лишається англійською.
  2. window = ["the", "cat", "sat", "on", "the", "mat"] — Дані або рахунок. Імена в коді англійські, сенс — у реченні кроку.
  3. ctr = Counter() — Дані або рахунок. Імена в коді англійські, сенс — у реченні кроку.
  4. for i, w in enumerate(window): — Повторення кроку для кожного елемента.
  5. for j in range(max(0, i-1), min(len(window), i+2)): — Повторення кроку для кожного елемента.
  6. if i != j: — Гілка: різний хід для різної умови.

def most_similar(table, word, topn=3):
    target = table[word]
    ranked = []
    for other, vec in table.items():
        if other != word:
            ranked.append((other, cosine(target, vec)))
    ranked.sort(key=lambda row: -row[1])
    return ranked[:topn]
print(most_similar(table, "good"))

"""Runnable demo for pair 28: Аналогія king−man+woman крихка: інший домен — інші сусіди."""

from __future__ import annotations

try:
    import math

    news = {'bank': (1.0, 0.1), 'loan': (0.9, 0.2), 'river': (0.1, 1.0)}
    tweets = {'bank': (0.4, 0.7), 'loan': (0.5, 0.4), 'river': (0.2, 0.9)}

    def cos(a, b):
        return sum(x * y for x, y in zip(a, b)) / (math.hypot(*a) * math.hypot(*b))

    def nearest(space, query):
        return max((w for w in space if w != query), key=lambda w: cos(space[query], space[w]))

    print('news', nearest(news, 'bank'), 'tweets', nearest(tweets, 'bank'))
    guess = (1.0 - 0.9 + 0.1, 0.0 - 0.1 + 0.9)
    print('fragile_analogy_vec', guess)
    assert nearest(news, 'bank') != nearest(tweets, 'bank')
except ModuleNotFoundError as exc:
    print('skip_missing_dep', getattr(exc, 'name', None) or exc)

На позиції 5 вектор дивиться на попередні позиції з вагами, які в сумі дають 1. Більша вага — сильніший внесок того слова.

Наступне слово беруть з розподілу. Якщо найбільша ймовірність 0.4, це ще не «єдине правильне слово», решта 0.6 лежить на інших токенах.

LSTM теж читає послідовність, але несе стислий стан далі. Трансформер на кожному кроці може глянути на інші позиції прямо.

Ми задаємо довжину контексту і словник. Ваги уваги рахує модель.

Ваги однієї позиції

Вони додатні і в сумі 1. Це внесок інших слів.

Що виходить

Розподіл на словник. Наступний шматок — вибір з нього, не готовий абзац.

Глибина пояснення

Слово в моделі — вектор фіксованої довжини. Близькі за вживанням слова опиняються ближче в цій сітці, не в алфавіті.

Нехай вектор має довжину 8. Два слова — дві вісімки. Схожість — скалярний добуток або відстань, не спільні літери.

Вектор не вписують руками по словнику на тисячі слів. Його зрушує навчання так, щоб сусіди по тексту допомагали вгадати наступний шматок або мітку.

Ми задаємо довжину вектора. Числа всередині змінює навчання.

1) Середовище (Python 3.10–3.14; інтернет потрібен лише для pip)
   На Python 3.14 gensim не ставиться — це нормально: Word2Vec навчається на numpy (повільніше, лише Skip-gram).
   python -m venv .venv
   .venv\Scripts\activate          (Windows)
   source .venv/bin/activate        (macOS / Linux)
   python -m pip install -U pip
   python -m pip install -r requirements.txt
   Перевірка: python -c "import nlp_vectors; print(nlp_vectors.BACKEND)"     → gensim або numpy

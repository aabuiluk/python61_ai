Працюйте в папці пакета. Спільні функції беріть з `nlp_vectors.py`: `clean_tokens`, `stopword_set`, `word_counts`, `Word2Vec`, `SHEET_W2V`.

## Завдання 1. Два жанри — два корпуси

За зразком `Lesson27_01_corpus_explore.py`.

1. Візьміть з Brown два жанри: `news` і `romance`:
   ```python
   from nltk.corpus import brown
   sents = brown.sents(categories="news")
   ```
2. Перетворіть кожен на список списків: нижній регістр, лише слова з літер.
3. Для кожного жанру надрукуйте: кількість речень, слів, розмір словника, частку слів, що трапились один раз, середню довжину речення.
4. Надрукуйте топ-10 слів без стоп-слів для кожного жанру поруч.
5. Одним реченням: чим відрізняються ці два корпуси і що це означає для моделі, навченої на кожному з них.

**Очікуваний результат:** таблиця з двох рядків і два списки топ-слів. У news 4604 речення по ~18 слів, у топі `state`, `year`, `president`. У romance 4415 речень по ~13 слів, у топі `could`, `like`, `thought`, `little`.

## Завдання 2. Word2Vec на жанрі

За зразком `Lesson27_03_train_word2vec.py`.

1. Навчіть два Word2Vec з параметрами аркуша (`vector_size=100, window=5, sg=1`), але `min_count=3`: один на news, другий на romance.
2. Для слів `man`, `house`, `money`, `night` надрукуйте 5 найближчих сусідів в обох моделях.
3. Порахуйте `similarity("man", "woman")` в обох моделях.
4. Двома реченнями: чому сусіди одного слова в двох моделях різні? Чи можна довіряти сусідам, навченим на 80 тисячах слів?

**Підказка:** якщо слова немає у словнику моделі, обробіть це через `if word in model.wv.key_to_index`, а не падінням з `KeyError`.

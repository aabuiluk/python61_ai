Завдання визначення пневмонії за зображенням

сьогодні

Вхід — знімок, не таблиця аналізів. Вихід — клас. Велику мережу не вчать з нуля на малій пачці знімків: беруть уже навчені ваги і донавчають хвіст.

Кадр кольоровий або зведений до трьох каналів, часто 224×224, бо така сітка була в мережі, з якої взяли ваги. Знімок грудної клітки спочатку приводять до цієї форми.

Заморозити ранні шари означає: їхні ваги не отримують крок. Навчається останній шар під два класи: є ознака пневмонії чи ні.

Частка влучань знову ховає пропуски. Для знімка важливіше, скільки справжніх випадків знайшли.

Чужий набір знімків не тягнуть у заняття цілком. На парі достатньо форми батча і плану, які шари заморожені.

for p in backbone.parameters():
    p.requires_grad = False

Що задаємо ми

Розмір кадру, які шари заморожені, скільки класів у хвості.

Що вже знайдено раніше

Ранні ядра, навчені на інших картинках. Їх не вигадують заново на десяти знімках.

Етика

Пропуск хвороби і хибна тривога — різні ціни. Одна частка влучань цього не показує.

Старт: LeNet vs AlexNet vs ResNet

теорія

Глибина пояснення

До цього моменту ми тренували одну просту CNN. Тепер важливо побачити, як еволюціонували архітектури й навіщо зʼявились skip connections.

До цього моменту ми тренували одну просту CNN. Тепер важливо побачити, як еволюціонували архітектури й навіщо зʼявились skip connections.

LeNet добре лягає на цифри. AlexNet показав силу глибокого CV на ImageNet. ResNet додав residual-шлях, який полегшує проходження градієнта через велику глибину.

Коротко

ImageNet — це датасет і конкурс, а не окрема мережа. Мережі на ньому прославились, але не дорівнюють йому.

Повний медичний датасет Chest X-Ray не кладемо в репозиторій. Нижче — відтворюваний каркас на синтетичних «знімках» 28×28, той самий цикл, що на пневмонії: NCHW → CNN → BCE/CE → threshold → recall.

Коли зʼявиться папка train/NORMAL і train/PNEUMONIA, замініть генератор на ImageFolder. Метрики й split лишаються.

import numpy as np
import torch
from torch import nn
from sklearn.metrics import recall_score, precision_score

torch.manual_seed(0)
n, c, h, w = 64, 1, 28, 28
x = torch.rand(n, c, h, w)
y = (x.mean(dim=(1, 2, 3)) > 0.5).long()

class TinyCXR(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Flatten(), nn.Linear(8 * 14 * 14, 2),
        )
    def forward(self, batch):
        return self.net(batch)

model = TinyCXR()
loss_fn = nn.CrossEntropyLoss()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
for _ in range(3):
    opt.zero_grad()
    logits = model(x)
    loss = loss_fn(logits, y)
    loss.backward()
    opt.step()
pred = model(x).argmax(1).numpy()
print('recall', round(recall_score(y.numpy(), pred, zero_division=0), 3))
print('precision', round(precision_score(y.numpy(), pred, zero_division=0), 3))
# -> метрики існують і змінюються після кроків Adam; це каркас, не клінічний AUC

Accuracy на незбалансованих знімках бреше. Для пневмонії дивіться recall позитивного класу й матрицю помилок.

"""Runnable demo for pair 25: Пневмонія: patient-level split, межі Grad-CAM, ліцензії Kermany/NIH, не клініка."""

from __future__ import annotations

try:
    import pandas as pd
    from sklearn.model_selection import GroupShuffleSplit, train_test_split

    df = pd.DataFrame({
        'image_id': [f'img{i}' for i in range(6)],
        'patient_id': [1, 1, 2, 2, 3, 3],
        'label': [0, 1, 0, 1, 0, 1],
    })
    rand = train_test_split(df.index, test_size=0.33, random_state=0)
    leak = set(df.loc[rand[0], 'patient_id']) & set(df.loc[rand[1], 'patient_id'])
    gtr, gte = next(GroupShuffleSplit(1, test_size=0.33, random_state=0).split(df, groups=df['patient_id']))
    clean = set(df.loc[gtr, 'patient_id']) & set(df.loc[gte, 'patient_id'])
    print('random_patient_leak', leak)
    print('group_patient_leak', clean)
    assert leak and not clean
    card = {
        'intended_use': 'classroom patient-split protocol',
        'out_of_scope': 'not a diagnosis; Grad-CAM is sensitivity, not lesion proof',
        'licenses': ['Kermany Mendeley', 'NIH ChestX-ray14'],
    }
    print(card)
except ModuleNotFoundError as exc:
    print('skip_missing_dep', getattr(exc, 'name', None) or exc)

Готові ваги лишають, коли своїх кадрів мало. Тоді навчають лише хвіст під ваші класи, а ранні шари не чіпають.

Ми задаємо розмір входу і скільки класів у хвості. Ранні ваги або беремо готові, або вчимо з нуля, якщо кадрів достатньо.

Форма кадру

Сірий (1, 28, 28), колір (3, висота, ширина).

Що задаємо ми

Чи заморожувати ранні ваги і скільки виходів у хвості.

Що виходить

Оцінка класу для нового кадру тієї самої форми.

Архітектури зору

додатково

Глибина пояснення

Перед захистом показують шлях, який інша людина запускає: дані, команда, метрика, межа висновку.

Архітектура на схемах збігається з файлами. Якщо на схемі є перевірка, у коді є ця перевірка. Якщо метрика 0.70, поруч лежить набір, на якому її порахували.

Запобіжник — явна відмова: порожній вхід, відсутній документ, форма не збіглася. Мовчки підставити значення — не запобіжник.

Ми задаємо, що саме здаємо. Число метрики вже пораховане на відкладених прикладах, його не малюють у слайді вручну.

Що відкривається

Дані, команда запуску, метрика, межа.

Що задаємо ми

Список файлів і речення, чого система не обіцяє.

Що виходить

Той самий показ на чужому запуску, не лише на вашому екрані.

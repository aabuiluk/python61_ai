У презентації 25: «Старт: LeNet vs AlexNet vs ResNet», «таблиця архітектур», «CIFAR-10: batch 3×32×32», «навіщо skip connection».

**Що побачите:** три мережі отримують той самий батч `(4, 3, 32, 32)` і всі видають `(4, 10)`, але параметрів у них 62 тисячі, 6,5 мільйона й 11,2 мільйона.

**Головне:** ResNet додає до виходу блоку його ж вхід (`F(x) + x`). Завдяки цьому градієнт доходить до перших шарів навіть у дуже глибокій мережі.

### Крок 2 · 0:25–0:35 · Прийоми навчання

## Словничок

| Термін | Простими словами |
|---|---|
| CNN | нейромережа, яка дивиться на картинку маленьким вікном (фільтром) і шукає візерунки |
| residual / skip connection | «обхідна дорога»: вихід блоку = його робота + його вхід |
| аугментація | випадкові невеликі зміни навчальних картинок, щоб модель не запамʼятовувала дрібниці |
| transfer learning | беремо мережу, вже навчену на великих даних, і довчаємо лише останній шар під свою задачу |
| balanced accuracy | середнє з точності на здорових і точності на хворих |
| OCR | розпізнавання тексту на зображенні |
| CER | частка неправильно розпізнаних символів |
| токен | окрема одиниця тексту |
| стоп-слово | часте слово без змісту, яке прибирають перед аналізом |
| стем / лема | обрізана основа слова / словникова форма слова |

## Відповіді для самоперевірки

1. Кожна мережа закінчується шаром на 10 виходів — по одному на клас CIFAR-10.
2. Свій вхід після ReLU, тобто блок нічого не зіпсує.
3. LayerNorm: вона рахує статистику всередині одного прикладу і не залежить від розміру батча.
4. 0.75, хоча модель нічого не вміє. Тому дивимось також recall, precision і balanced accuracy.
5. Пропустити хворого — це false negative, тому для скринінгу важливіший recall.
6. Якщо вибирати за test, він перестає бути чесною перевіркою: ми підганяємо модель під нього.
7. 512 · 2 + 2 = 1026 параметрів з приблизно 11 мільйонів.
8. Дві літери стануть одним «символом», і мережа поверне одну неправильну літеру (як TT → W в `ocr_test_09`).

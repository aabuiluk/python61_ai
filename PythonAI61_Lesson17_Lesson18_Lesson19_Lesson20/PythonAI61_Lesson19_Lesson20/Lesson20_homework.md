# Домашнє · пара 20. Кейс: передбачення серцевих захворювань (NN)

Вікно пари — 80 хв. База й практика — у заліку цієї пари. Stretch — після заняття.

## База

Exit ticket з цієї пари — мінімальний артефакт, який ви здаєте як доказ.

**Що зробити**

1. Одне речення ризику FN для хвороби + яка метрика важливіша за accuracy.
2. Звірте з очікуваним результатом нижче.

**Що здати.** Текст, мінікод або схема файлів. Не рядок «зрозумів тему» без доказу.

**Готово, коли.** Recall/PR для позитивного класу; дисклеймер «не діагноз».

## Практика

Обовʼязкові блоки в презентації мають мітку «обовʼязково» / «Практика · у вікні 80 хв».

**Що зробити**

1. Відкрийте презентацію цієї пари.
2. Пройдіть блоки База і Практика: повторіть зразок, потім аналог X.1 самостійно (у роздатку немає готового файлу).
3. Зафіксуйте seed / `random_state = 42`, якщо тренуєте модель.
4. Запустіть Support Intelligence модуля 4: `project/support_intelligence/m04_mlp.py`  
   Команда (з теки проєкту): `python3 m04_mlp.py`
5. Напишіть одне речення Responsible AI: Медичні/кадрові ознаки: overfitting на шум — це ризик для людини, не лише для loss.

**Що здати.** Скрипт або ноутбук з print результату + речення RAI.

**Готово, коли.** Код запускається локально, без ключів і без обовʼязкової мережі.

## Stretch

Необовʼязково для заліку пари, але якщо час дозволяє — бажано ознайомитись.

**Тема.** 5 рядків responsible AI для цього кейсу.

**Що зробити**

1. Напишіть 5 рядків responsible AI саме для цього медичного/чутливого кейсу.
2. Рядки: дані (що не збирати), помилка FN, помилка FP, HITL, дисклеймер «не діагноз».
3. Не копіюйте загальні гасла — привʼяжіть до вашої метрики з пари.
4. Підпишіть, яку метрику покажете користувачеві замість голої accuracy.

**Що здати.** `rai_case.md` — рівно 5 рядків + метрика.

**Готово, коли.** 5 конкретних рядків і назва метрики, не «бути етичним».

**Завдання ITSTEP з міткою Stretch.** Відкрийте блок у презентації з міткою Stretch / take-home. Спочатку повторіть офіційне завдання за зразком коду на слайді. Потім зробіть аналог X.1 самостійно (у роздатку немає готового файлу). Збережіть свій скрипт і один рядок: який print ви очікуєте і що побачили.

2. Linear(10, 32) — як учора

10 входів × 32 нейрони = 320 ваг. 32 bias. Разом 352. Формула нейрона та сама: сума wᵢxᵢ + b.

Глибина пояснення

Навіщо це взагалі потрібно

BatchNorm потрібен не щоб «мережа глибша виглядала». Він стабілізує масштаб активацій між шарами, тому крива часто гладша. Навіщо PNG: на око не видно, чи BN допоміг, якщо є лише останній loss. Порівняння з baseline без BN на тих самих даних — єдиний чесний аргумент, що зміна щось змінила.

Новий акцент: Траєкторії SGD / momentum / Adam на спільному бюджеті кроків.

"""Runnable demo for pair 18: Траєкторії SGD / momentum / Adam на спільному бюджеті кроків."""

from __future__ import annotations

try:
    import torch

    def run(name: str, ctor, lr: float, steps: int = 40) -> float:
        torch.manual_seed(0)
        p = torch.tensor([3.0, 3.0], requires_grad=True)
        opt = ctor([p], lr=lr)
        for _ in range(steps):
            opt.zero_grad()
            loss = p[0] ** 2 + 10.0 * p[1] ** 2
            loss.backward()
            opt.step()
        print(name, [round(float(v), 3) for v in p.detach()], float(loss))
        return float(loss)

    sgd = run('sgd', torch.optim.SGD, 0.05)
    mom = run('momentum', lambda params, lr: torch.optim.SGD(params, lr=lr, momentum=0.9), 0.05)
    adam = run('adam', torch.optim.Adam, 0.2)
    assert min(sgd, mom, adam) < sgd or True
    print('budget', 40)
except ModuleNotFoundError as exc:
    print('skip_missing_dep', getattr(exc, 'name', None) or exc)

Ліцензія і етика

Синтетична чаша; не видавати переможця за універсальне правило для MLP.

Для даних про людей, здоров’я, дохід або поведінку перевірте representation, privacy і можливу шкоду. Навчальна модель не є діагнозом, скорингом у проді чи юридичним висновком.

Split і leakage

  • Split до fit scaler / imputer / vocabulary / PCA / augment / threshold.
  • Час: не кладіть майбутнє в минуле.
  • Люди, пацієнти, документи: group split, не випадкові файли.
  • Test не для підбору порога, early stopping або промпта.

Dropout і регуляризація в нейромережах

На попередній парі ви зібрали стабільний zero_grad → backward → step. Тепер той самий HealthRisk-MLP треба зробити чесним до тесту: однаковий split, різні hidden-активації, Dropout лише під час навчання і метрики на eval().

Пари 15–16 дали один нейрон і цикл навчання. Сьогодні чесний експеримент на MLP: чотири hidden-активації на одному split, потім Dropout(p=0.3). Метрики — лише в eval() + no_grad(); висновок дивиться на train/test gap, а не на «магію шару». Нижче — повні сценарії дошки і приклади виконання завдань 1–2 для викладача.

Карта пари — 10 кроків. Кожен крок має схему. Далі лекція розгортає той самий порядок: регуляризація → Dropout → train/eval → метрики на test.

Сьогоднішній якір — сигнал проти шуму і маска Dropout. Чотири hidden-активації на тому самому вході — це не «яка красивіша», а таблиця форм до MAE.

Пояснення зібрано з програми ITSTEP, книжки Траска, практичного 4.2, Astra і методичного шару тієї ж програми. Авторські PDF і відео в слайд не кладемо.

  2. Роздаток. Практику ITSTEP не розвʼязуємо в слайді. Формат завдань N / N.1 / N.2 лишається як у версії 1.12.
  3. Книжки курсу. Траск, Грокаємо глибоке навчання, розд. 8 (сигнал/шум, Dropout, пакет) і розд. 9 (активація, ReLU / softmax). Grokking Algorithms — про пошук, не про ці пари.
  4. Аркуш ITSTEP і статті з OD. Практичне 4.2: HealthRisk, ReLU / Tanh / LeakyReLU / Swish, Dropout p=0.3, BatchNorm, зведена таблиця. Гайд активацій з індексу OD підтверджує: місце функції — hidden або вихід, не «яка красивіша». NetAcad Introduction to Modern AI дає загальний контур ШІ, без підміни сьогоднішнього коду.
  5. Astra, модуль 4. Без нелінійності кілька Linear згортаються в один. train() і eval() — різні процедури. Dropout і BatchNorm — окремі важелі від no_grad().

  7. Додатковий шар цієї пари. У train Dropout масштабує живі активації на 1/(1−p). MC-dropout — не режим за замовчуванням. Скелет сторінки (chrome / rail / stage) не змінює зміст прикладу.

Глибина пояснення

За замовчуванням — скорочено в цьому блоці. «Детально» відкриває повний код і графіки лише тут.

  1. 1 · train() вмикає маску Dropout. eval() її знімає.
  2. 2 · На одному тензорі одиниць видно: train стрибає, eval стабільний.

eval() тут — evaluation mode, режим перевірки мережі. Це не команда «порахуй метрику» і не кнопка Run.

У PyTorch шар має два режими:

layer.train()  # режим навчання
layer.eval()   # режим перевірки / тесту

На цьому демо це критично через Dropout. Візьміть шість одиниць. У train() при p=0.5 приблизно половина стане нулями, а решта — двійками, не одиницями. Чому 2, а не 1? PyTorch масштабує живі значення на 1 / (1 − p). При p=0.5 це рівно 2. Так середнє лишається близько до 1, хоча половина нейронів «мовчить».

У eval() Dropout вимикається. Шість одиниць так і виходять шістьма одиницями, середнє = 1.0. Випадковості немає: ви дивитесь на навчену мережу, а не кидаєте монетку.

 0.5 → 0.5
 2.0 → 2.0

Відʼємне вмирає. Параметрів немає. На цьому стенді ReLU — робочий старт завдання 1.

4. Tanh стискає в (−1, 1)

-2.0 → ≈ −0.96
 2.0 → ≈  0.96

Може насичуватись: градієнт на «поличках» малий. Не «гірша за ReLU на око» — дивіться MAE на test.

5. LeakyReLU

-2.0 → −0.02   (α=0.01)
-0.5 → −0.005
 0.5 →  0.5

Відʼємне не нуль. Іноді рятує «мертві» ReLU-нейрони. Усе ще 0 навчуваних параметрів.

6. Swish = nn.SiLU()

На аркуші написано Swish. У torch це nn.SiLU(), не окремий nn.Swish. Формула x·sigmoid(x): відʼємне не вбиває наглухо, додатне майже як x.

GELU — аналог 1.1, пʼятий рядок. Орієнтир завдання 1 його не містить.

7. Як це лягає в MLP

Linear(10, 32)
    → act     ← ось це порівнюємо
    → Linear(32, 1)   вихід лінійний

Dropout ставте після act, не замість неї. Завдання 1: чотири рядки, один split, один seed, 40 епох, той самий Adam lr.

8. Точний рахунок на x = −2

Одна точка, чотири формули. Так само рахує нейрон у hidden, лише x там — уже зважена сума, не «сира» ознака.

sigmoid(−2) = 1 / (1 + e²) ≈ 0.119
ReLU(−2)      = max(0, −2)           =  0
LeakyReLU(−2) = 0.01 · (−2)          = −0.02
Tanh(−2)      ≈ (e⁻² − e²)/(e⁻² + e²) ≈ −0.964
SiLU(−2)      = (−2) · sigmoid(−2)   ≈ −0.238

На x = 2: ReLU і LeakyReLU дають 2; Tanh ≈ 0.964; SiLU ≈ 1.762. Додатне ReLU не чіпає; Swish трохи менше за x.

теорія

Глибина пояснення

За замовчуванням — скорочено в цьому блоці. «Детально» відкриває повний код і графіки лише тут.

  1. 1 · Dropout ставлять після hidden-активації, не замість неї.

  3. 3 · Шар не додає параметрів. На eval він прозорий.

Коли hidden уже навчився сильних співзалежностей, Dropout випадково прибирає частину шляхів.

Практичне правило для цієї пари: Dropout ставимо після активації hidden-шару. Тоді мережа вчиться працювати не з одним «улюбленим» нейроном, а з розподіленим представленням.

    "LeakyReLU": nn.LeakyReLU(),
    "Swish": nn.SiLU(),
}
print("activation MAE R2")

    model = nn.Sequential(nn.Linear(10, 32), act, nn.Linear(32, 1))

        opt.zero_grad()

from torch import nn

x_te = torch.tensor(scaler.transform(X_te), dtype=torch.float32)
y_tr_t = torch.tensor(y_tr, dtype=torch.float32).view(-1, 1)


def train_eval(p: float) -> tuple[float, float, float]:
    torch.manual_seed(42)
    layers: list[nn.Module] = [nn.Linear(10, 32), nn.ReLU()]
    if p > 0:
        layers.append(nn.Dropout(p))
    layers.append(nn.Linear(32, 1))
    model = nn.Sequential(*layers)
    opt = torch.optim.Adam(model.parameters(), lr=1e-3)
    for _ in range(40):
        model.train()
        opt.zero_grad()
        nn.functional.mse_loss(model(x_tr), y_tr_t).backward()
        opt.step()
    model.eval()
    with torch.no_grad():
        tr = mean_absolute_error(y_tr, model(x_tr).numpy().ravel())
        te_pred = model(x_te).numpy().ravel()
    return tr, mean_absolute_error(y_te, te_pred), r2_score(y_te, te_pred)

print("config trainMAE testMAE R2 gap")
for p, label in ((0.0, "без Dropout"), (0.3, "Dropout 0.3")):
    tr, te, r2 = train_eval(p)
    print(label, round(tr, 3), round(te, 3), round(r2, 3), round(te - tr, 3))

from __future__ import annotations

try:
    import torch
    import torch.nn as nn

    layer = nn.Dropout(p=0.5)
    x = torch.ones(2000)
    layer.train()
    y_train = layer(x)
    layer.eval()
    y_eval = layer(x)
    print('train_mean', float(y_train.mean()), 'train_zeros', float((y_train == 0).float().mean()))
    print('eval_unique', set(y_eval.tolist()[:5]), 'eval_mean', float(y_eval.mean()))
    assert torch.allclose(y_eval, x)
    layer.train()
    mc = torch.stack([layer(x) for _ in range(5)]).mean(dim=1)
    print('mc_spread', float(mc.max() - mc.min()))
    print('mc_is_not_default_eval', True)

Основні обʼєкти matplotlib: Figure, Axes і безпечний старт через plt.subplots()

теорія

Figure — усе полотно графіка: розмір вікна, збереження у файл, місце для кількох координатних областей. Axes — конкретна система координат, де ви вже малюєте лінії, точки чи стовпчики. Найстабільніший старт один і той самий: fig, ax = plt.subplots().

Схема · де що знаходиться

Що за що відповідає

Figure

Контейнер зображення: figsize, tight_layout(), savefig(), кілька Axes поруч.

Axes

Одна система координат: plot, hist, bar, підписи осей, сітка, легенда.

plt.subplots()

Одразу дає пару fig, ax. Далі малюєте на ax, а не через глобальний plt.plot.

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot([1, 2, 3], [1, 4, 9], marker="o", color="crimson")
ax.set_title("Мій перший графік")
ax.set_xlabel("X")
ax.set_ylabel("Y")
ax.grid(True, alpha=0.25)
plt.show()
Зверніть увагу

Навіть якщо plt.plot(...) працює, одразу звикайте до fig, ax = plt.subplots(). Так простіше додати другий графік поруч, зберегти PNG і не змішувати «pyplot-стан» з обʼєктним стилем у одному ноутбуці.

figsize задається в дюймах, пікселі = дюйми × dpi. При (7, 4) і dpi=100 полотно 700×400 px; при dpi=200 — 1400×800. Збережений PNG «розмитий на проєкторі» часто має малий dpi, а не «поганий plot». fig.savefig(..., dpi=150) фіксує щільність окремо від розміру вікна ноутбука.

Кілька Axes: plt.subplots(1, 2, sharey=True) дає два обʼєкти ax[0], ax[1] зі спільною шкалою y — саме так порівнюють гістограми P1 і P3. Глобальний plt.title після цього підпише не ту вісь. Кожна система координат — свій ax.set_title.

Коротко

fig відповідає за файл і розмір, ax — за дані й підписи. Не змішуйте plt.plot із другим ax на тій самій фігурі.

Додатково: fig — полотно, ax — система координат; plt.plot пише «в останній ax»

додатковий матеріал

OO API: fig, ax = plt.subplots(). Далі ax.plot, ax.set_title, fig.savefig. Pyplot-стан plt.plot малює на «поточному» Axes — у ноутбуці з двома графіками легко підписати не ту вісь. Навіть один графік стартуйте з subplots.

import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot([1, 2, 3], [1, 4, 9], marker="o")
ax.set_xlabel("x")
ax.set_ylabel("y")
fig.tight_layout()
fig.savefig("pair7_axes.png", dpi=120)
  • plt.subplots(1, 2) дає масив Axes — підписи кажіть кожному axes[0], axes[1].
  • figsize живе на Figure, не на лінії.
  • plt.show() показує; savefig до show, інакше у деяких backend порожній файл.
Зверніть увагу

Якщо title зʼявився на попередній картинці — ви змішали pyplot-стан і OO. Поверніться до fig, ax = plt.subplots() і малюйте лише на ax.

Figure — контейнер; Axes — місце, де живуть дані й підписи. plt.plot без явних ax пише в «поточний» axes, який легко виявиться іншим subplot. Зверніть увагу: savefig ріже підписи, якщо не constrained_layout/tight_layout — це не «matplotlib зламав шрифт», а bbox полотна.

Два виклики plt.figure() — два вікна. Другий plot не додається на перший fig, якщо ви знову не передали ax.

Побудова графіків функцій: x, y, лінія, маркери, підписи

теорія

Функціональний графік починається з двох масивів однакової довжини: x і y. Далі ми вирішуємо, що підкреслити: безперервність лінією, окремі вимірювання маркерами, чи тренд через колір і заголовок.

import matplotlib.pyplot as plt

x = list(range(1, 11))
y = [value ** 2 for value in x]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(x, y, color="crimson", marker="o", linewidth=2)
ax.set_title("Графік функції y = x²")
ax.set_xlabel("X")
ax.set_ylabel("Y")
plt.show()

Графік · y = x²

Памʼятка аргументів ax.plot

x і y

Два масиви однакової довжини. Якщо довжини різні — графік не побудується.

marker

Показує реальні точки, а не лише зʼєднану лінію. Корисно для вимірювань.

color / linewidth

Контраст і товщина. Без підписів осей колір сам по собі нічого не пояснює.

Зверніть увагу

Часто плутають «графік функції» і «графік набору даних». Зверніть увагу: одна й та сама команда plot() працює і для математики, і для реальних вимірювань, але сенс осі x може бути різним.

Щоб лінія синуса виглядала гладкою, крок по x має бути дрібним відносно періоду. Для y=sin(x) на [0, 2π] пʼять точок дають ламану з кроком ~72°, двісті точок np.linspace — вже «крива». Це дискретизація графіка, не математика функції.

Вимірювання хвилин по тікетах — інший сенс x: категорія або час події, не неперервний аргумент. Там маркери обовʼязкові, а лінія між T-1004 і T-1008 нічого не інтерполює. Одна команда ax.plot, два контракти: сітка функції vs ряд спостережень.

Часта пастка

Мало точок на періоді малює «іншу функцію». Перед plot перевірте len(x) і чи x монотонний.

Додатково: лінія зʼєднує точки в порядку масиву — невідсортований x малює зигзаг

додатковий матеріал

ax.plot(x, y) малює ламану в порядку елементів, не «математичну функцію». Якщо x — перемішані вимірювання, лінія стрибатиме. Для функції зберіть x через np.linspace (монотонний). Маркери показують реальні спостереження; густа лінія без маркерів — неперервна модель.

import numpy as np
import matplotlib.pyplot as plt
x = np.array([3, 1, 2])
y = x ** 2
fig, ax = plt.subplots()
ax.plot(x, y, marker="o")          # зигзаг 9→1→4
xs = np.sort(x)
ax.plot(xs, xs ** 2, marker="s")   # монотонна парабола
  • Довжини x і y мають збігатися — інакше ValueError, не «підрізати».
  • Часовий ряд: x — час, не індекс 0..n, якщо шкала нерівномірна.
  • ITSTEP y=x²: маркери на цілих x, лінія зʼєднує їх як модель.
Часта пастка

Графік «функції» з випадковим порядком x виглядає як шум. Перед plot перевірте, що x монотонний, або малюйте scatter без лінії.

ax.plot зʼєднує точки в порядку масиву, не за зростанням x. Невідсортований x малює зигзаг, який виглядає як «шум моделі», хоча це порядок індексу. scatter не зʼєднує — тому для хмари він чесніший.

Зверніть увагу: drawstyle='steps-post' змінює інтерполяцію між тими самими точками. Це вже інша візуальна модель, не «згладжування даних».

Побудова гістограм розподілу: що показує histogram і коли вона потрібна

теорія

Histogram показує не порядок точок, а розподіл значень: скільки спостережень потрапило в кожен інтервал. Вона доречна, коли ми хочемо відповісти на питання «де більшість значень?» і «чи є хвости або викиди?».

import matplotlib.pyplot as plt

scores = [58, 61, 64, 64, 68, 70, 71, 73, 74, 75, 77, 78, 82, 85, 88]

fig, ax = plt.subplots(figsize=(7, 4))
ax.hist(scores, bins=6, color="steelblue", edgecolor="white")
ax.set_title("Розподіл балів")
ax.set_xlabel("Бал")
ax.set_ylabel("Кількість студентів")
plt.show()

Графік · розподіл балів

Коли histogram, а коли line?

Histogram

Потрібно побачити форму розподілу: симетрія, скупчення, викиди.

Line plot

Потрібно побачити зміну показника вздовж часу або послідовності.

Bar plot

Порівнюємо окремі категорії: місяці, студенти, товари.

Зверніть увагу

Не називайте стовпчасту діаграму і гістограму одним словом «барчики». У гістограмі стовпці — це числові інтервали (bins); у bar-plot стовпці — це категорії (місяць, товар, група).

При density=True площа стовпчиків ≈ 1: висота — оцінка щільності, не лічильник. Бін ширини h з k точками має висоту k/(n·h). На 80 тікетах, h=10 хв, 16 тікетів у біні → 16/(80·10)=0.02. Порівнювати таку вісь з «кількість студентів» не можна.

Правило Фрідмана–Діаконіса: h = 2·IQR·n−1/3. Воно підлаштовує ширину під розкид і розмір вибірки, а не під кругле «bins=10». На малій n формула дає широкі біни — і це чесніше, ніж пила з порожніх інтервалів.

n, iqr, h = 80, 20, None
h = 2 * iqr * n ** (-1 / 3)
print(round(h, 1))  # ширина біна, хв
Зверніть увагу

Підпис осі y має казати, counts це чи density. Без цього стовпчик «0.02» нечитабельний.

Додатково: hist ріже неперервну вісь на біни; bar ставить готові категорії

додатковий матеріал

Гістограма відповідає «скільки спостережень у інтервалі?». Bar відповідає «яке значення в цієї категорії?». Поставити ax.bar(range(len(scores)), scores) — це не розподіл, а ряд значень по індексу. Навпаки, hist на місяцях «січень..червень» зліпить категорії в штучні інтервали.

import matplotlib.pyplot as plt
scores = [58, 61, 64, 64, 68, 70, 71, 73, 74, 75, 77, 78, 82, 85, 88]
fig, ax = plt.subplots()
ax.hist(scores, bins=6, edgecolor="white")
ax.set_xlabel("Бал")
ax.set_ylabel("Кількість")
  • bins=6 змінює висоту стовпчиків; зафіксуйте bins у звіті.
  • Вісь y гістограми — лічильник (або щільність), не «бал».
  • Дискретний рейтинг 1..5: value_counts().sort_index() + bar.
Зверніть увагу

Якщо підпис осі x — імена людей, вам потрібен bar, не hist. Якщо підпис — «сума чека, грн» — hist або box.

hist ріже неперервну вісь; bar ставить уже готові категорії на дискретні позиції. Підписати hist іменами людей — категорії зникнуть у бінах. Зверніть увагу: counts з np.histogram можна передати в bar, якщо edges вже зафіксовані — тоді bar лише малює, а бінування вже сталось.

Оформлення графіка: title, labels, legend, grid, figsize

теорія

Графік без підписів осей майже завжди марний. Мінімум, який має бути на навчальній візуалізації: заголовок, підписи осей, адекватний розмір фігури, а за потреби legend і grid.

import matplotlib.pyplot as plt

hours = [0, 4, 8, 12, 16, 20, 24]
temp = [15, 14, 18, 22, 25, 20, 17]

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(hours, temp, color="darkorange", marker="o", label="Температура")
ax.set_title("Температура протягом доби")
ax.set_xlabel("Година")
ax.set_ylabel("°C")
ax.grid(True, alpha=0.3)
ax.legend()
plt.show()
1. Даніx і y однакової довжини
2. Побудоваax.plot() або ax.bar()
3. Поясненняset_title, set_xlabel, set_ylabel
4. Читабельністьgrid, legend, контрастні кольори
title + labels

Заголовок каже, що зображено. Осі кажуть, в яких одиницях. Без цього графік не читається сам.

legend + grid

Legend потрібна, щойно на графіку більше одного ряду. Сітка допомагає зчитувати піки, не «прикрашає».

Чеклист перед plt.show()

Чи зрозуміло, що за величина на осі X? Чи видно одиниці виміру? Чи не потрібно увімкнути сітку? Якщо відповідь «ні», графік ще сирий.

Коротко

Один графік — одна думка. Підписи осей і legend — частина задачі, не «прикраса в кінці».

Сітка з alpha=0.3 має бути тихішою за дані: лінія або стовпчик лишаються контрастнішими. Якщо grid чорний і товстий, око читає клітинки, не SLA-поріг. ax.axhline(60, ls="--") для порогу 60 хв — окремий шар змісту, не «ще одна сітка».

Один графік — одна теза. Якщо треба і тренд хвилин, і частки каналів, це два Axes (або два файли), не легенда з пʼяти кольорів на одній парі осей. figsize=(8, 4) при довгих підписах channel все одно обріже текст: тоді rotation або barh, не дрібніший шрифт «щоб влізло».

Коротко

Чеклист: одиниці на осях, поріг як окрема лінія, сітка тихіша за дані. Колір не замінює підпис.

Додатково: сітка й cividis / tableau-colorblind10 замість райдуги

додатковий матеріал

Оформлення — частина змісту: без підписів осей графік не читається, без сітки важко порівняти висоти, без палітри для дальтонізму «червоний vs зелений» зникає. ax.grid(True, alpha=0.3) тримайте легким. Для ліній — cycler tableau-colorblind10; для неперервної шкали — cividis, не jet.

import matplotlib.pyplot as plt
plt.style.use("tableau-colorblind10")
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot([0, 4, 8, 12, 16, 20, 24], [15, 14, 18, 22, 25, 20, 17], marker="o")
ax.set_title("Температура протягом доби")
ax.set_xlabel("Година")
ax.set_ylabel("°C")
ax.grid(True, alpha=0.3)
ax.legend(["температура"])
  • Title каже думку одним рядком, не повторює підписи осей дослівно.
  • legend потрібна, коли ліній ≥ 2; для однієї — можна title.
  • ITSTEP завдання 5 прямо просить сітку — це не «прикраса».
Зверніть увагу

Палітра rainbow гарно виглядає на слайді і погано в друку / проєкторі. cividis і tableau-colorblind10 залишаються читабельними в градаціях сірого.

Сітка допомагає читати значення, але не замінює ticks. cividis і tableau-colorblind10 зберігають порядок на друку/проекторі краще за jet, який створює фальшиві межі в жовтій зоні.

Зверніть увагу: cycler кольорів глобальний (rcParams). Друга лінія «сама стала оранжевою» — не магія ax, а наступний колір циклу.

ax1.set_title("розподіл")
fig.tight_layout()

Додатково: mini-lab з histogram

додатковий матеріал

Згенеруйте 30 випадкових балів від 50 до 100, побудуйте hist з bins=5, а потім повторіть з bins=10. Порівняйте, як змінюється «зернистість» розподілу.

import random
import matplotlib.pyplot as plt

scores = [random.randint(50, 100) for _ in range(30)]
plt.hist(scores, bins=5, color="teal", edgecolor="white")
plt.title("Histogram of scores")
plt.show()

Bins змінюють історію. Занадто мало інтервалів — «гора» без форми; занадто багато — гребінка з одиниць. У книжці курсу про візуалізацію розподілів прямо сказано: binning може не дати потрібної роздільності, якщо розподіл скошений.

import random
import matplotlib.pyplot as plt
scores = [random.randint(50, 100) for _ in range(40)]
fig, axes = plt.subplots(1, 2, figsize=(8, 3), sharey=True)
for ax, bins in zip(axes, (5, 12)):
    ax.hist(scores, bins=bins, color="teal", edgecolor="white")
    ax.set_title(f"bins={bins}")
fig.tight_layout(); plt.show()

Порівнюйте гістограми на однаковому наборі чисел. Інакше змінюєте і дані, і bins одночасно.

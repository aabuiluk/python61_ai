# Домашнє · пара 23. CNN для рукописних цифр

Зробіть один скрипт на локальних `assets/digits/digits_*.npz`. Другий Softmax перед CrossEntropy не ставте.

## 1

Завантажте train/test npz. Надрукуйте shape images і скільки прикладів кожного класу 0–9 у train.

## 2

Зберіть `Conv2d(1,16,3) → ReLU → MaxPool2d(2) → Linear(16*13*13, 10)`. Вхід `(4,1,28,28)` дає `(4,10)`.

## 3

Навчіть мережу мінімум 3 епохи (Adam + CrossEntropy). Збережіть checkpoint з `model_state` (state_dict), `history`, mean/std. Відновіть ваги в новий екземпляр і перевірте, що логіти на одному кадрі збігаються.

## 4

Порахуйте test accuracy. Одним реченням: чому argmax по логітах достатній для класу, а Softmax потрібен для ймовірностей.

Рубрика (100): коректність форм і save/load, assert або зафіксований вивід, читабельні імена, межа «синтетика ≠ прод MNIST».

Роздаток пар 23–24.
Тема: Побудова згорткової нейронної мережі для класифікації рукописних цифр.

1) Середовище
   python -m venv .venv
   .venv\Scripts\activate          (Windows)
   source .venv/bin/activate        (macOS / Linux)
   python -m pip install -U pip
   python -m pip install -r requirements.txt

2) Дані (уже в архіві)
   assets/digits/digits_train.npz   — навчальний набір (images, labels)
   assets/digits/digits_test.npz    — тестовий набір
   assets/digits/png/digit_{0-9}_v{1-3}.png — по 3 картинки на цифру

3) Запуск навчання (пара 23)
   python Lesson23_train_digits_cnn.py
   → зʼявиться mnist_cnn.pth і test accuracy

4) Перевірка PNG
   python Lesson23_predict_png.py

5) Стабілізація (пара 24)
   python Lesson24_stable_digits_cnn.py

6) Презентації офлайн
   Lesson23_00_presentation.html
   Lesson24_00_presentation.html

Поняття датасету

основний блок15 хв

Датасет — структурований набір спостережень, зібраний під конкретне питання. У табличному вигляді:

  • рядок (row / sample / observation) — один обʼєкт (клієнт, будинок, транзакція);
  • стовпець (column / feature) — характеристика обʼєкта;
  • цільова ознака (target / label) — те, що передбачаємо (якщо задача supervised).

Приклад навчального датасету «оренда квартир»:

area_m2roomsdistricthas_elevatorrent_uah
421Центр118500
612Сихів015200
783Личаків124100

Тут rent_uah — target; решта — features.

Додатковий матеріал

Якість датасету важливіша за «крутість» моделі на старті:

  • репрезентативність (чи покриває реальний прод?);
  • витоки цільової змінної (leakage);
  • пропуски, дублікати, помилки вимірювання;
  • часова коректність (train у минулому, test у майбутньому).

Ознаки в датасеті та цільова ознака

основний блок18 хв

Класифікація ознак (практична):

  • числові неперервні: площа, температура, сума чека;
  • числові дискретні: кількість кімнат, кількість покупок;
  • категоріальні nominal: район, бренд (немає порядку);
  • категоріальні ordinal: рівень освіти, rating 1–5;
  • datetime / час: дата реєстрації, година кліку;
  • текст / image / audio: потребують окремих пайплайнів.

Цільова ознака визначає тип задачі: число → регресія, клас → класифікація.

import csv
from pathlib import Path

rows = [
    {"area_m2": 42, "rooms": 1, "district": "Центр", "has_elevator": 1, "rent_uah": 18500},
    {"area_m2": 61, "rooms": 2, "district": "Сихів", "has_elevator": 0, "rent_uah": 15200},
    {"area_m2": 78, "rooms": 3, "district": "Личаків", "has_elevator": 1, "rent_uah": 24100},
]

path = Path("rent_sample.csv")
with path.open("w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=rows[0].keys())
    writer.writeheader()
    writer.writerows(rows)

feature_cols = ["area_m2", "rooms", "district", "has_elevator"]
target_col = "rent_uah"
print("X:", feature_cols)
print("y:", target_col)
print("saved:", path.resolve())
Додатковий матеріал

Feature store мислення: одна й та сама сира колонка може перетворитись на кілька ознак (день тижня, is_weekend, days_since_registration). Це вже feature engineering — тема наступних модулів, але рамку варто закласти зараз.

Питання групі: чи можна брати price_per_m2 = rent/area як ознаку, якщо target = rent? Обговоріть leakage / circularity.

Знайомство з Jupyter Notebook та JupyterLab

основний блок15 хв

Jupyter — середовище інтерактивних обчислень: код, текст, графіки в одному документі.

  • Notebook (.ipynb) — класичний інтерфейс «лінійка комірок».
  • JupyterLab — IDE-подібна оболонка: файли, кілька ноутбуків, термінал, вкладення.
  • Альтернативи в індустрії: VS Code notebooks, Google Colab, managed cloud notebooks.

Встановлення (локально):

python -m pip install jupyterlab ipykernel
python -m ipykernel install --user --name python61-ai --display-name "Python AI Materials AI"
jupyter lab
Для AI/DS: ноутбук ідеальний для EDA і пояснення. Для продакшену код виносять у модулі .py, тести і пайплайни. Навчіть студентів не тримати «все життя» лише в .ipynb.
Додатковий матеріал

Kernel — процес Python, який виконує код. Restart kernel очищає стан змінних. Це критично: порядок виконання комірок ≠ порядок у файлі, якщо запускали вибірково.

Ноутбуки, комірки та основні команди

основний блок12 хв
  • Code cell — виконуваний Python.
  • Markdown cell — пояснення, формули, заголовки.
  • Shift+Enter — виконати й перейти далі; Ctrl/Cmd+Enter — виконати на місці.
  • Esc — command mode; Enter — edit mode.
  • Корисні magic: %timeit, %matplotlib inline, !ls (обережно).

Мінімальний каркас навчального ноутбука:

# 1) imports
from pathlib import Path
import csv

# 2) parameters
DATA = Path("rent_sample.csv")

# 3) load
with DATA.open(encoding="utf-8") as f:
    data = list(csv.DictReader(f))

# 4) quick check
print(len(data), "rows")
print(data[0])
Додатковий матеріал

Гігієна ноутбука для викладача:

  1. Restart Kernel & Run All перед здачею/демо.
  2. Верхня комірка — imports + константи.
  3. Не тримати секрети (API keys) у .ipynb.
  4. Великі виводи / сирі логи — згортати або прибирати.

Глибоко: data dictionary і схема

основний блок8 хв

Перед моделюванням заведіть data dictionary — навіть на 1 сторінку:

КолонкаТипОписДопустимі значенняРоль
area_m2floatплоща> 0feature
districtcategoryрайондовідник районівfeature
rent_uahfloatоренда/міс> 0target
 
schema = {
    "area_m2": {"dtype": "float", "role": "feature", "checks": [" > 0 "]},
    "district": {"dtype": "category", "role": "feature", "checks": ["in dictionary"]},
    "rent_uah": {"dtype": "float", "role": "target", "checks": [" > 0 "]},
}
for col, meta in schema.items():
    print(col, meta["role"], meta["dtype"])
Додатковий матеріал

У командах це рятує від «тихої» зміни сенсу колонки (наприклад, rent у грн vs дол.). На курсі вимагайте короткий dictionary у кожному ноутбуці EDA.
